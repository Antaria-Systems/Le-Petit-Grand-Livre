# Politique de sécurité

## Signaler une vulnérabilité

Si vous découvrez une faille de sécurité dans Le Petit Grand Livre (accès non autorisé, fuite de données, contournement de l'occultation…), **ne la publiez pas dans une issue publique**.

Écrivez à **contact.lpgl@antaria-systems.fr** avec :

- une description du problème et de son impact ;
- les étapes pour le reproduire (adresse, requête, fichier) ;
- vos coordonnées si vous souhaitez être tenu informé ou crédité.

Nous accusons réception sous 72 heures et vous tenons au courant de la correction. Merci de nous laisser un délai raisonnable avant toute divulgation.

## Donnée personnelle visible sur un document publié

Ce n'est pas une faille du code mais c'est urgent : écrivez à la même adresse en indiquant la commune, le document et la page. Le document est retiré puis corrigé au plus vite.

## Périmètre

- Le site https://lpgl.antaria-systems.fr et son administration ;
- le code de ce dépôt.

Les tests de charge, l'ingénierie sociale et les attaques contre l'infrastructure de tiers (Cloudflare, Authentik, relais de messagerie) sont hors périmètre.

Mesures en place : [docs/securite.md](docs/securite.md).
